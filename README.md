# learn-french-with-armenian-russian

This is how I'm learning French pronunciation. Not a textbook. I learn through songs and poetry — Fred Nevché, French 79, etc. When I wanted to read lyrics aloud, every pronunciation guide either used IPA (useless unless you've studied linguistics) or English approximations (wrong).

So I built this instead. A system using the three languages I actually speak — Armenian, Russian, Spanish — where each alphabet handles only what it's good at:

- **Armenian ղ** for every French R (that gh throat friction — not the Russian Р, not the Spanish tap)

- **Russian Cyrillic** for Ж, nasals, and vowel anchors

- **Spanish** for vocabulary that's basically free

If this is useful to you, copy it. Change my name, swap in your artists, adjust whatever doesn't fit your profile. The system is the part that matters.
